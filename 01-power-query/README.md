# Power Query

This section documents studies and practical exercises involving **data extraction, cleaning and transformation** with Power Query.

## Topics

- Importing data from different sources
- Data type validation
- Removing and filtering rows
- Renaming and reorganizing columns
- Handling null values and inconsistencies
- Merging and appending queries
- Creating reusable transformation steps
- Preparing datasets for analytical models

## Why it matters

Before a dashboard can answer business questions, the underlying data needs to be reliable. Power Query acts as the preparation layer between raw sources and the analytical model.

> Raw data → Clean data → Reliable analysis
