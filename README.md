## About this repository

This repository documents my learning journey and practical projects in **Data Analytics and Business Intelligence**.

The goal is not only to build dashboards, but to understand the complete analytical process: transforming raw data, designing reliable data models, defining meaningful business metrics and communicating insights through clear visualizations.

> A good dashboard does not simply display data — it helps someone make a better decision.

---

## Analytics Workflow

```text
Raw Data
   ↓
Power Query
   ↓
Data Cleaning & Transformation
   ↓
Data Modeling
   ↓
DAX Measures & KPIs
   ↓
Data Visualization
   ↓
Business Insights
   ↓
Decision Making
```

## What I want to demonstrate

Through this repository, I aim to demonstrate the ability to move beyond charts and understand the analytical reasoning behind a BI solution:

**Business Question → Data → Transformation → Model → Metric → Visualization → Insight → Decision**

This approach connects technical knowledge with business context — an essential part of working with Data Analytics and Data Science.

---

## Projects

Projects will be added progressively as they are developed. Each project will document:

- the business problem;
- the dataset and data sources;
- the transformation process;
- the data model;
- the main DAX measures and KPIs;
- dashboard design decisions;
- insights and conclusions.

This keeps the repository focused on **real analytical reasoning**, rather than only finished dashboard screenshots.
