# DAX — Data Analysis Expressions

This section is dedicated to analytical calculations developed with **DAX** in Power BI.

## Topics

- Measures vs. calculated columns
- Aggregations
- `CALCULATE`
- Filter context
- Row context
- Conditional calculations
- Percentage and variance analysis
- Time intelligence
- KPI calculations

## Objective

DAX transforms a data model into an analytical model. Instead of only storing values, the model begins answering business questions through reusable measures and indicators.

Examples and practical measures will be added as the studies progress.
